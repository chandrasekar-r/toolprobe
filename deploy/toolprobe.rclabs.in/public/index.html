toolprobe

CI for tool calling. This page is static. It does not call OpenAI, Anthropic, Gemini, or Workers AI, and it does not proxy those APIs.

Source: github.com/chandrasekar-r/toolprobe

What the CLI includes

The released CLI has a client for each of these APIs:

  • openai — OpenAI-compatible POST {base}/chat/completions.
  • anthropic — Anthropic Messages POST /v1/messages tool use.
  • gemini — Gemini generateContent function calling.
  • cloudflare — Workers AI POST /accounts/{account_id}/ai/run/{model}.

Tests for the Anthropic, Gemini, and Workers AI clients use local fixtures. They do not call those providers.

Mock

A green toolprobe run --mock is not a live provider result. --mock replays each probe's mock: block in process. It does not call the Anthropic, Gemini, or Workers AI clients.

toolprobe run --mock --probes probes/default
