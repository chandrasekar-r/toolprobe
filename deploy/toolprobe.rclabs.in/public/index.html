toolprobe

CI for tool calling. This page is static. It does not proxy model APIs and it does not use Workers AI.

Source: github.com/chandrasekar-r/toolprobe

Mock (no network, not a live result)

toolprobe run --mock --probes probes/default
toolprobe run --provider anthropic --mock --probes probes/default
toolprobe run --provider gemini --mock --probes probes/default
toolprobe run --provider cloudflare --mock --probes probes/default

Providers

  • openai — POST {base}/chat/completions. Key: TOOLPROBE_API_KEY or OPENAI_API_KEY.
  • anthropic — Messages /v1/messages tool use. Key: ANTHROPIC_API_KEY.
  • gemini — generateContent function calling. Key: GEMINI_API_KEY. Pass --model yourself.
  • cloudflare — Workers AI /ai/run. Key: CLOUDFLARE_API_TOKEN. Account: CLOUDFLARE_ACCOUNT_ID.

All 17 default probes run on each provider. None are skipped.
