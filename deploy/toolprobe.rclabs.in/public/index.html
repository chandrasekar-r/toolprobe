CI for tool calling. This page is static HTML and CSS. It does not call or proxy any provider.

How a run moves

Three paths. Each one is labeled as not a live result. A live run is a different path, and this page does not show one.

Not a live result

This page

This page does not call or proxy any provider.

BrowserReads this file only.
No requestNo fetch, no form, no proxy.
No providerOpenAI, Anthropic, Gemini, and Workers AI are not contacted.

Not a live result

OpenAI --mock

OpenAI --mock stays in process and does not build an HTTP request.

Probe fileThe mock: block is the whole reply.
In processThe synthesizer builds the result locally.
No HTTPNo chat/completions request is built or sent.

Not a live result

anthropic, gemini, and cloudflare --mock

--mock builds that provider's native request and parses a local fixture. The transport does not dial.

Native requestMessages, generateContent, or /ai/run JSON is built in the client.
Local fixtureThe reply is prepared in process from the probe.
No dialRoundTrip returns that fixture and does not open a connection.

Different path

Live run

A live run would send the native request to the provider. This page does not take that path, and it does not report that a live run happened.

toolprobe run --mock --probes probes/default
toolprobe run --provider anthropic --mock --probes probes/default
toolprobe run --provider gemini --mock --probes probes/default
toolprobe run --provider cloudflare --mock --probes probes/default

Those commands are the offline paths above. A green mock run is not a live provider result.
