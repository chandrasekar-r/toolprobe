toolprobe

CI for tool calling. This page is static. It does not call OpenAI, Anthropic, Gemini, or Workers AI, and it does not proxy those APIs.

Source: github.com/chandrasekar-r/toolprobe

Offline mock

A green toolprobe run --mock is not a live provider result. Nothing is dialed.

For anthropic, gemini, and cloudflare, --mock builds that provider's native request and parses a local fixture through the same client. The HTTP transport returns the fixture in process and does not dial. If --model is omitted, the request uses the placeholder id toolprobe-mock, which is not a published model.

OpenAI --mock stays on the in-process synthesizer. It does not build an HTTP request.

toolprobe run --mock --probes probes/default
toolprobe run --provider anthropic --mock --probes probes/default
toolprobe run --provider gemini --mock --probes probes/default
toolprobe run --provider cloudflare --mock --probes probes/default

Clients

The CLI has a client for each of these APIs. The commands above exercise the offline mock path only.

  • openai — OpenAI-compatible POST {base}/chat/completions.
  • anthropic — Anthropic Messages POST /v1/messages tool use.
  • gemini — Gemini generateContent function calling.
  • cloudflare — Workers AI POST /accounts/{account_id}/ai/run/{model}.
